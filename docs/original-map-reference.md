## 統治模式規則

原作規則：踩上控制點即完成佔領，沒有讀條也不需持續站立。**每持有一個控制點，每五秒得一分**，
因此持有兩點的得分速度是一點的兩倍。先達得分上限或時間結束時分數最高的隊伍獲勝。原作地圖
一律是三個控制點。
